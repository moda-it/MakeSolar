# MakeSolar

Вебзастосунок для проєктування сонячної електростанції на скатному даху з профнастилу.
Будує 3D-модель даху, розкладає панелі й блоки кріплення, моделює рух Сонця, рахує тіні
від перешкод, річний виробіток енергії, кошторис і строк окупності.

Курсова робота. Стек: React 19, TypeScript, Three.js (React Three Fiber), Vite, Vitest.

## Запуск

```bash
npm install
npm run dev      # режим розробки, http://localhost:5173
npm test         # модульні тести
npm run build    # production-збірка в dist/
```

## Можливості

| Розділ | Що вміє |
|---|---|
| Дах | ширина, довжина схилу, нахил, азимут; параметри хвилі профнастилу |
| Панелі | готові моделі (Jinko, JA Solar, LONGi) або власні розміри; відступи від країв; проміжки |
| Розміщення | автоматично «максимум панелей» або вручну: додати, перетягнути з магнітом, видалити |
| Кріплення | блоки 20/30/40 см, перевірка, що блок лягає щонайменше на 2 хвилі |
| Перешкоди | димарі, вентвиходи: розмір, перетягування, зона безпеки 30 см |
| Сонце | широта, дата, сонячний час; траєкторія Сонця, схід і захід, полярні день і ніч |
| Тіні | справжні тіні в 3D-сцені та розрахунок втрат від затінення для кожної панелі |
| Енергія | графік потужності за ясний день, виробіток по місяцях і за рік |
| Кошторис | вартість панелей і блоків кріплення, окупність |
| Проєкт | автозбереження в браузері, збереження й відкриття JSON-файлу, звіт PDF |

## Як рахується

### Положення Сонця (`src/solar/sunPosition.ts`)

- Схилення за Купером: δ = 23,45° · sin(360/365 · (284 + n)), де n — номер дня.
- Годинний кут: H = 15° · (t − 12), t — сонячний час.
- Висота: sin h = sin φ · sin δ + cos φ · cos δ · cos H.
- Азимут: A = atan2(sin H, cos H · sin φ − tg δ · cos φ) + 180°.
- Схід і захід: cos H₀ = −tg φ · tg δ; якщо |cos H₀| ≥ 1, настає полярний день або ніч.

### Система координат даху (`src/solar/roofFrame.ts`)

У сцені дах повертається навколо вертикалі на кут, що відповідає азимуту, і нахиляється на кут
нахилу. Вектор на Сонце переводиться в локальні координати даху зворотними поворотами. Після
цього локальна вісь Y збігається з нормаллю до схилу, і cos кута падіння дорівнює просто y-компоненті.

### Опромінення (`src/solar/energy.ts`)

- Оптична маса атмосфери за Кастеном–Янгом.
- Пряме нормальне випромінювання за моделлю Мейнела: DNI = 1361 · 0,7^(AM^0,678) Вт/м².
- Розсіяне випромінювання ≈ 10% прямого (ясне небо).
- Похила площина, ізотропна модель Лю–Джордана:
  G = DNI · cos θ · (1 − s) + DHI · (1 + cos β)/2 + GHI · ρ · (1 − cos β)/2,
  де s — частка панелі в тіні, ρ = 0,2 — альбедо ґрунту.
- Потужність панелі: P = Pном · G / 1000 · PR, PR = 0,8 (втрати в інверторі, кабелях, від нагріву).
- Енергія за день: інтеграл потужності методом трапецій з кроком 10 хв.

### Хмарність

Модель ясного неба не знає про погоду. Тому для кожного місяця обчислюється коефіцієнт:
типовий місячний виробіток 1 кВт панелей у Житомирі (південь, 35°) ділиться на результат моделі
для тих самих умов. Річний виробіток = Σ (ясний день місяця × днів у місяці × коефіцієнт).
Типові значення (`ZHYTOMYR_REFERENCE_KWH_PER_KWP`, ≈ 1080 кВт·год/кВт за рік) орієнтовні, порядку
даних PVGIS. Для точнішого результату їх можна замінити даними з
[PVGIS](https://re.jrc.ec.europa.eu/pvg_tools/en/) для конкретної адреси.

### Тіні (`src/solar/shading.ts`)

На кожній панелі береться сітка 3×3 точки. З кожної точки пускається промінь до Сонця
і перевіряється перетин з паралелепіпедами перешкод (метод «плит», slab test). Частка
затінених точок прибирає відповідну частку прямого випромінювання; розсіяне лишається.

### Кошторис і окупність (`src/economics/estimate.ts`)

- Вартість = панелі + блоки кріплення.
- Окупність = вартість ÷ (річний виробіток × тариф).

Стартові ціни орієнтовні ринкові, їх можна змінити у вкладці «Кошторис».

## Структура

```
src/
  App.tsx               стан застосунку та інтерфейс
  components/           поля, перемикачі, графіки, звіт для друку
  scene/                3D-сцена: дах, панелі, блоки, перешкоди, Сонце, лінійки
  geometry/             розкладка панелей і блоків, профіль даху, правила розміщення
  solar/                положення Сонця, система координат даху, тіні, енергія
  economics/            кошторис і окупність
  project/              збереження та відкриття проєкту
  utils/                математика, форматування чисел
  __tests__/            модульні тести (Vitest)
```

## Тести

`npm test` запускає 59 тестів для чистої логіки: положення Сонця (схилення в дні сонцестоянь
і рівнодень, тривалість дня, полярний день), переведення координат, перетин променя з
перешкодою, модель опромінення, калібрування річного виробітку, розкладка панелей,
кошторис і окупність, перевірка файлу проєкту, форматування чисел.

## Обмеження

- Погода врахована середніми місячними коефіцієнтами, а не погодинними даними.
- Тіні рахуються лише від перешкод; тінь від сусідніх будинків і дерев не моделюється.
- Панелі лежать паралельно до схилу (без додаткових кронштейнів нахилу).
- Ціни потрібно оновлювати вручну.
